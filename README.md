# Sales Performance Dashboard

## Overview
This project is an interactive Sales Performance Dashboard built using Power BI.

## Tools Used
- Power BI
- Excel
- Power Query

## Key Metrics
- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Orders: 5K
- Total Quantity Sold: 38K

## Dashboard Features
- Sales Analysis by Category
- Profit Analysis by Category
- Regional Sales Performance
- Customer Segment Analysis
- Ship Mode Analysis
- KPI Tracking

## Business Insights
The dashboard helps identify top-performing products, profitable categories, and regional sales trends to support business decision-making.
